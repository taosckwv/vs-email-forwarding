## 使用说明

- 任务**按依赖顺序**排列，不要跳序执行。
- 每个任务行固定四段：**编号 → 前置 → 描述 → 对应的 `FR-n` / `AC-n`**。写法：
  - `` - [ ] `T-3` （前置 `T-1`）`<任务描述>` — `FR-n` / `AC-n` ``
  - 没有前置时写 **「（前置 无）」**，必须显式写出来——用来区分「真的没有前置」与「忘了填」。
- **前置是依赖边，不是顺序说明**：`T-3` 的前置写 `T-1`，表示「`T-1` 完成前 `T-3` 不能开工」。阶段划分只是可读性分组，**真正的任务图由前置字段定义**；跨阶段依赖必须写出（例：仓储任务的前置是迁移任务，而不是「它在上一阶段所以自然就绪」）。
- 每个任务必须标注它对应的 `FR-n` / `AC-n`；标不出来的任务说明它不该存在（或者规格缺了一条需求）。
- 完成一项就改成 `[x]`，并在提交信息里引用 spec 编号。
- 若发现任务与 `spec.md` 冲突：**先改 spec 并重新确认**，不要默默按代码走。
- 所有任务完成后，回到 `spec.md` 填写「验收结果」。
